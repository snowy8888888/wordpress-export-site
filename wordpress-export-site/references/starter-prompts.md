# 开场 prompt 与需求问题

下面模板适用于不同产品和不同公司的外贸人。方括号内为客户自己的信息；缺少的信息保持待问，不能套用上一家公司的邮箱、号码、域名、认证或产品数据。问题先检查对话已知答案，不重复询问。

## 最初始 prompt：适合尚未整理资料的人

```text
我在做外贸，想做一个面向海外客户的官网，用来展示产品、介绍公司和收集询盘。

请使用 $wordpress-export-site 帮我完成建站。网站使用 WordPress，页面要能用 Elementor 编辑器继续修改；我的 Elementor 版本如果不清楚，请先问我。不要默认购买 Pro 或加入购物结账。

先根据我已有的信息问必要问题，帮助我明确品牌、产品、目标市场、客户、网站语言、合作方式、联系方式和素材。可以把问题分成少量几组，用我容易理解的中文询问，告诉我哪些可以稍后补充。

得到基本资料后，请先整理网站需求和页面结构，再实际制作可编辑页面、产品详情、询盘表单、WhatsApp、目录下载及基础 SEO。需要连接网站时告诉我应该提供什么访问方式；账号密码通过安全连接配置处理，不写进网站内容、报告或这个 skill。

完成后测试桌面和手机、正式页面链接、表单与目录下载，交付编辑入口、维护说明和备份。不要虚构产品参数、认证、客户案例、价格、工厂规模或 SEO 收录结果。我的联系方式必须使用我本次提供的资料。
```

如果对方的 AI 工具尚未安装这个 skill，把第一句替换为“请作为 WordPress 外贸官网建站助手帮我完成下面任务”，并把本文件夹的 SKILL.md 和相应 references 提供给该工具；不要声称 skill 会自动连接对方网站。

## 已有资料时：可直接填写的 prompt

```text
请使用 $wordpress-export-site 制作/更新我的外贸官网，需求如下：

品牌：[品牌]
公司：[公司名]
业务所在地：[国家/城市，公开公司地址可稍后提供]
主要产品及型号：[产品分类和型号]
主要目标市场：[国家/地区]
目标客户：[批发商/经销商/品牌商/工程客户/零售客户/不限]
前台语言：[英文/其他语言]
合作方式：[现货/批发/OEM/ODM/工程定制等，按实际填写]
有证据的产品认证：[认证名称及适用型号；没有则留空]
网站目标：[展示产品和收集询盘/其他]
业务收件邮箱：[我的邮箱]
WhatsApp：[带国家区号的我的号码]
正式域名：[我的域名]
Elementor：[免费版/已有 Pro/还不确定]
已有素材：[Logo/产品图片/目录 PDF/规格表/其他]
图片要求：[纯产品图与使用场景图分别用在哪些页面；产品外形和比例不可改变]
视觉偏好或参考：[配色/风格/参考网站，无则由你提出合适方案]
隐私资料：[公司法定名称/地址/询盘保存期限，未知请标记待补充]
Google Search Console：[已验证/已有账号但未添加网站/没有账号]
目前网站：[新网站/旧站更新；希望保留的页面和功能]

请先补问关键缺失信息，已回答的不要重复问。页面文字、图片、按钮、产品规格以及 header/footer 都要尽量用 Elementor 原生元素，我需要能选中 header/footer 容器并 Save as Template。

请制作适合我的页面结构，配置我的询盘邮箱和 WhatsApp、型号预填及目录下载；为可发布页面做好标题、描述、canonical、图片 alt、分享图和 sitemap。先核对网站现状再改动，避免覆盖我已有编辑。

测试邮件只有在我明确同意测试收件邮箱后才发送，标注 TEST；分开报告表单成功、询盘保存与邮箱实际收到。完成后交付公开网址、Elementor 编辑入口、模板说明、手机/桌面截图、SEO 检查结果与配置备份，并说明仍待我提供的资料。
```

## AI 最开始应问的问题

不要一次把所有可选问题都抛给客户。首轮优先问 1–6，能从已有资料回答的跳过；7–10 在相关步骤问。用户说“其他由你决定”时自行选择常规方案，只有真正影响实施的缺项继续问。

1. **你卖什么、叫什么？** 品牌名、公司名、主要产品和是否已有型号/规格资料？
2. **卖给谁、卖到哪里？** 主要国家/地区、客户类型、需要什么网站语言？
3. **网站要完成什么？** 只展示产品并收集询盘，还是要在线下单？是否支持 OEM、ODM、批发或工程定制？
4. **客户怎样联系你？** 询盘发到哪个业务邮箱？WhatsApp 是哪个带国家区号的号码？是否需要其他联系渠道？
5. **你已有哪种网站条件？** 有没有域名和 WordPress？用 Elementor 免费版还是 Pro？是新建还是修改旧站，哪些内容要保留？
6. **有哪些可以用的素材？** Logo、产品图片、使用场景图、目录 PDF、规格、认证文件？是否有带客户/第三方品牌的素材需要先确认？
7. **喜欢什么视觉风格？** 有没有参考网站或偏好颜色？产品页用纯产品图，其他页面需要使用场景吗？
8. **哪些业务数字能公开？** MOQ、交期、样品、产能、质保与证书适用型号有没有确认资料？没有就通过咨询获取，不编造。
9. **隐私政策需要哪些实际信息？** 公司法定名称和公开地址、询盘保存期限、实际邮件/托管服务商、是否使用分析/广告 cookies？
10. **上线和搜索工具状态如何？** 正式域名是哪一个？哪些页面可发布？是否已有 Search Console 验证？邮箱能否进行一次明确标注的测试？

## 首轮回答后的需求摘要

在开始制作时用简短中文复述：谁的品牌、什么产品、面向哪些市场、哪种合作、哪些页面、WordPress/Elementor 版本、业务联系方式和缺失项。联系方式只是这个项目的数据，不能保存成所有客户通用的默认值。接着执行已授权的工作，不停留在提示词或计划阶段。
