# B2B Product Website Skill

面向不同行业的 B2B 产品询盘站建站技能，默认使用 WordPress、Elementor 和 WooCommerce。

覆盖产品目录整理、原生产品与分类、行业采购文案、产品场景图与 WebP、工厂照片与视频、WhatsApp 询价、表单记录、邮件通知及客户回执、桌面和手机验收。

## 安装

[下载完整技能 ZIP](https://github.com/snowy8888888/wordpress-export-site/raw/refs/heads/main/b2b-product-website-skill.zip)，将其中的 `b2b-product-website` 文件夹放到 `~/.codex/skills/`。Windows 对应 `%USERPROFILE%\.codex\skills\`。保留文件夹内的 `references` 和 `agents`。

若技能列表尚未刷新，重启 Codex 后调用。

## 使用

```text
使用 $b2b-product-website，根据我的产品目录和设计参考，
为我的行业建设一个 B2B 产品询盘网站。
```

准备自己的产品目录、型号与规格、图片、公司资料、目标客户、目标市场、联系方式和设计参考，并连接自己的 WordPress。网站操作、图像生成及邮箱认证需要对方环境提供相应能力，技能文件本身不包含这些服务。

页面结构、文案、产品比较项和视觉根据实际行业调整。Starlight 智能锁内容为案例参考，产品数量和配色按新项目决定。最终效果需通过实际内容与页面验收。
